# Dragonwilds Save Editor (Xbox)

A browser-only character save editor for **RuneScape: Dragonwilds**, built for Xbox saves.

## Use it

Open `index.html` in any modern browser — or visit the live site once deployed. Click **Browse for Save File** and pick your character save.

## Trust

Everything runs locally in your browser. Your save file is never uploaded anywhere.

## Features

- Inventory editing (items, quantities up to 999999, slot ranges)
- Vitals editing (health, stamina, food, water, endurance, grace periods)
- Skills, perks, journal, conditions
- Gear / loadout management, including the Dragonbane Cape (Alpha Cape)
- Full item icon set (948 icons)
- Preserves unknown save data, key order, and formatting on write

## Xbox saves

The editor accepts the extensionless save files synced from Xbox. After editing, download the file and sync it back through the Xbox cloud the same way you pulled it.
